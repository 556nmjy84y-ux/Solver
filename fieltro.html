Cómo leerlo. Cada casilla es una clase de mano: suited arriba de la diagonal, offsuit abajo. Las bandas de color son la mezcla de frecuencias, con el código de colores de las fichas. Toca una casilla para ver combo por combo, y toca una acción para bajar por el árbol.

Alcance. Este motor resuelve river, donde el board ya está completo. Turn y flop requieren recorrer cientos de cartas por venir y no caben en la memoria que iOS concede a una página web — para eso está la versión de Python en tu computadora.
